🏛️ 1. The Big Picture: "History Meets Codecraft"

Imagine a video game that combines a time machine, Minecraft, and a coding school.

Most computer science courses teach abstract math problems like "reverse this string" or "sort a list of numbers". Epoch Nexus Academy turns every coding challenge into an active historical crisis where students must program solutions under real legal, economic, and political constraints:

🏛️
Classical Antiquity (Ancient Greece)
You don't just write if/else statements — you write the democratic vote-counting algorithm that tallies 6,000 citizens' votes in the Athenian Agora and strictly enforces Roman Tribunician Vetoes.
⛵
Age of Discovery (Venice 1500s)
You don't just do string math — you decrypt intercepted diplomatic cables using Caesar and Vigenère ciphers to protect merchant fleets and balance spice trade tariffs across the Mediterranean.
🏭
Industrial Revolution (Manchester 1840s)
You don't just write loops — you program a discrete-time factory state machine balancing mill production, coal smog pollution, worker satisfaction, and strike risks.
🌐
Modern Governance (2030+ CE)
You implement Quadratic Voting (Cost = V²) to simulate multilateral UN treaty ratifications and prevent botnet exploits on consensus ledgers.

⚙️ 6. How It Works Under the Hood

Here is the exact lifecycle of a code execution when a student clicks "Run Sandbox":

1
AST Security Static Guard: The server-side Python parser analyzes the syntax tree before running. It instantly blocks forbidden operations (like __subclasses__ object introspection, external imports, and nested loop bombs).
2
Pyodide WebAssembly (Zero-Latency Browser Runtime): The student's code runs directly inside their web browser using a WebAssembly-compiled Python 3.12 engine. Over 96% of executions require 0ms network latency!
3
Automated Historical Test Suite: The engine evaluates the solution against multiple edge cases (e.g. low quorum, active vetoes, cipher offsets, strike risks).
4
3D World Update: The voxel engine renders the outcome: citizen urns ignite green, galleons sail forward, or smokestacks puff smoke.
5
SOC2 Audit & Soulbound Web3 Minting: A SHA-256 cryptographic proof is added to the hash-chained audit ledger. Upon track completion, a non-transferable ERC-5192 Soulbound Credential NFT is minted to the student's wallet address.

🚀 11. Quickstart & Standalone Executable

Option A: Standalone Windows Executable (Zero Setup)

No Python, Node.js, or Git required! Ideal for sharing with friends or school lab computers:

  1. Double-click EpochNexusAcademy.exe (or unzip EpochNexusAcademy-Standalone.zip).
  2. A terminal window starts the local engine and automatically opens your default browser to http://localhost:8000.
  3. To stop, close the terminal window or press Ctrl+C.

Option B: Developer Setup from Source

# 1. Clone the repository
git clone https://github.com/drawafterschool-ai/epoch-nexus.git
cd epoch-nexus

# 2. Start Backend API
cd backend
python -m venv venv
.\venv\Scripts\activate   # Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000

# 3. Start Frontend Client (in a separate terminal)
cd ../frontend
npm install
npm run dev
