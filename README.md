> **Epoch Nexus Academy (ENA)** is an educational platform synthesizing **World History**, **Political Science & Civics**, and **STEM Computer Science**. Students navigate historical inflection points through branching narratives, a living **Minecraft-style 3D Voxel World**, and an integrated safe in-browser Python coding sandbox. Completed mastery milestones issue verifiable Soulbound digital credentials on EVM-compatible L2 networks.

---

## 🌟 The Core Idea: "History Meets Codecraft"

Normally, computer science courses teach abstract math like *"sort this list of numbers"*. 

**Epoch Nexus Academy** turns every coding lesson into an active **historical crisis**:
- **🏛️ Ancient Greece (Classical Antiquity)**: You don't just write `if/else` conditions — you code the democratic vote-counting algorithm that tallies 6,000 citizens' votes in the Athenian Agora and enforces Roman Tribunician vetoes.
- **⛵ Renaissance Venice (Age of Discovery)**: You don't just manipulate strings — you decrypt intercepted diplomatic cables using Caesar & Vigenère ciphers to protect merchant fleets and negotiate spice tariffs.
- **🏭 Victorian England (Industrial Revolution)**: You don't just write loops — you code an industrial state machine balancing textile factory output, coal smog pollution, worker satisfaction, and strike risks.
- **🌐 Modern Governance (2030+ CE)**: You implement **Quadratic Voting** ($\text{Cost} = V^2$) to simulate multilateral UN treaty ratifications and prevent botnet exploits on consensus ledgers.

The interface is divided into four synchronized quadrants:

```

│ 1. HISTORICAL COUNCIL & STORY         │ 2. MINECRAFT 3D VOXEL SANDBOX         │
```

1. **🏛️ Historical Council (Top-Left)**: Interactive dialogue trees featuring **Pericles**, **Niccolò Machiavelli**, **Ada Lovelace**, and **Eleanor Roosevelt** providing lore, objectives, and legal constraints.
2. **⛏️ Minecraft 3D Voxel World (Top-Right)**:

   - Watch the golden **Turtle Builder Bot** fly out and construct monuments block-by-block when your code passes!
   - 3-Way Mode Switcher: `[ ⛏️ Minecraft Voxel ]` | `[ 🌐 3D Smooth ]` | `[ 🖼️ 2D View ]`.
3. **🧩 Dual-Mode Code Editor (Bottom-Left)**:
   - **Visual Logic Blocks (Scratch / Blockly Style)**: Snap colorful cards together (conditions, loops, math, returns). Visual blocks automatically generate Python code in real time!

## 🚀 Key Features

### 1. ⛏️ Minecraft-Style Voxel Sandbox & Walkable Avatar
- **Living Block Worlds**: Athens Acropolis marble temples, Venetian water canals with bridges, Manchester brick mills with smoking chimneys, and cyber UN amphitheaters.
- **Walkable Avatar**: Full WASD movement, Spacebar jump with realistic gravity, 360° mouse look, and on-screen D-pad.
- **Code-to-Build Turtle Bot**: Students' Python code commands a golden builder bot to construct arches, pillars, and walls block-by-block.

### 2. 🧩 Dual-Mode Programming (Blocks & Python)
- Switch seamlessly between `[ 💻 Python ]` and `[ 🧩 Visual Blocks ]`.
- Visual cards snap together with constraint parameters and bidirectionally synchronize with the Monaco Python editor.

### 3. ⚠️ Dynamic Historical Crisis Shocks
- Inject real-time emergency events mid-simulation (*The Plague of Athens*, *Ottoman Naval Blockade*, *1842 Manchester General Strike*, *Sybil Botnet Attack*).
- Forces scholars to adapt their algorithms to sudden resource shocks.

### 4. ⚔️ Classroom Faction Tournaments
- Live team competition:
  - *The Delian League (Athens)* vs. *The Peloponnesian League (Sparta)*
  - *Republic of Venice* vs. *Republic of Genoa*
  - *Analytical Innovators (Lovelace)* vs. *Chartist Cooperative Alliance*
- Features a live tug-of-war score bar, team rosters, and faction perks.

### 5. ⚡ Infinite Track & Task Creator Studio
- Built-in AI scenario generator: enter any historical prompt (e.g. *"Ancient Egypt Nile Flooding"* or *"Space Station Accord"*) to synthesize a complete playable track, lore, tests, and 3D simulation in seconds!

### 6. 🎓 Institutional Educator Suite & AP Alignment
- Live classroom terminal monitor tracking active scholars.
- Direct alignment with **AP European History**, **AP U.S. Government**, and **AP Computer Science Principles**.
- 1-click gradebook CSV export for **Canvas LMS** and **Google Classroom**.

## 📦 Standalone Executable (Zero Installation)

You can run the entire platform as a single Windows executable without installing Node.js, Python, or Git:

- **Single Executable**: `EpochNexusAcademy.exe` (~20 MB)
- **Portable Zip**: `EpochNexusAcademy-Standalone.zip` (~20 MB)

Double-clicking `EpochNexusAcademy.exe` starts the local FastAPI server and automatically opens your browser to `http://localhost:8000`.

## 🛠️ Quickstart (Developers)

### Prerequisites
- Node.js 18+
- Python 3.10+

### 1. Clone & Setup
```bash
git clone https://github.com/drawafterschool-ai/epoch-nexus.git
cd epoch-nexus
```

### 2. Start Backend API
```bash
cd backend
python -m venv venv
.\venv\Scripts\activate   # On Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8000
```

### 3. Start Frontend Client
```bash
cd ../frontend
npm install
npm run dev
```
Open **`http://localhost:3000`** in your browser.

### 4. Run Automated Test Suites
```bash
python backend/tests/test_evaluator.py
python backend/tests/test_scalability_and_privacy.py
python backend/tests/test_educator_and_track3.py
python backend/tests/test_multiplayer_and_assessment.py
python backend/tests/test_infinite_studio.py
```
